# Security policy

## Supported version

Security fixes target the latest commit on the default branch and the latest
published release.

## Reporting a vulnerability

Please use GitHub's private vulnerability-reporting feature for this repository.
Do not open a public issue containing credentials, personal media, exploit
details, or a working safety bypass.

Include the affected version, impact, reproduction steps using synthetic data,
and any suggested mitigation. You should receive an initial response within
seven days.

Never include cloud API keys, local database contents, generated media, or
third-party personal data in a report.
